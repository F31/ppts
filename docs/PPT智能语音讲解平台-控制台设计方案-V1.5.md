# PPT 智能语音讲解平台——控制台设计方案 V1.5

> 版本：V1.5｜日期：2026-09-14｜状态：可用于 UI 设计、前端实施与接口联调的设计基线  
> 产品名称：智讲 PPT  
> 输入基线：用户提供的控制台结构、ChatGPT 上轮优化建议、《PPT讲解平台-控制台UI设计评审.md》（Claude）、《PPT自动讲解工具-技术方案-V4_0.md》。  
> 本版交付完整设计方案，不修改 V4.0 后端架构。用户已说明后端完成开发；本次未取得源码、Protobuf 定义和接口运行结果，因此文中服务名沿用 V4.0，新增字段与路由均为设计约定，须在联调表中映射，不代表已验证上线。

## 1. 产品目标与整合决策

智讲 PPT 帮助用户把现有 PPT 制作为可校对、可试听、可增量修改的语音讲解。核心体验为：导入 → 校对讲稿 → 试听调整 → 生成 → 播放与导出。

V1.5 以统一讲解项目组织源文件、页面、讲稿、音频、任务和成品。首页帮助用户开始或继续工作；工作台承担连续创作；设置承担个人及租户管理。桌面与 Web 提供完整工作台，移动端侧重审阅和播放。

### 1.1 两份建议的采纳与取舍

| 议题 | V1.5 最终决策 | 采纳与修正理由 |
|---|---|---|
| 首页 | 创作型首页，最近项目优先，统计次之 | 采纳双方对任务导向的共识；采用 Claude 的首次空状态 |
| 项目与已配音 PPT | 一级仅保留“讲解项目”；项目内设“成品与版本” | 采纳 Claude 的统一项目入口，避免两套资源认知 |
| 全局成品库 | 能力具备且有跨项目查找需求后开放，作为聚合视图 | 保留 ChatGPT 的成果查找优势，不复制或迁移项目 |
| 工作台 | 页面缩略图 + PPT 预览 + 讲稿编辑三栏；属性在右栏页签/抽屉中 | 保留双方三栏思路，避免长期打开第四栏挤压内容 |
| 个人与租户设置 | 同一设置入口、明确两组导航、真实子路由 | 采纳 Claude 的作用域分组与角色可见性 |
| 登录 | 已有正式认证优先；开发入口双端显式门控 | 邮箱自助注册与租户发现列可选扩展，不以新增认证阻塞本轮 |
| 任务反馈 | 第一轮纳入轮询/已有事件流、失败恢复及取消状态 | 采纳 Claude 的实时反馈要求及 ChatGPT 的任务语义 |
| 修改与成品 | 草稿可变、任务固定输入、成品不可变；音频过期显式标记 | 采纳 ChatGPT 的版本与增量生成要求，对齐 V4.0 |
| 全局命令面板 | P2，项目名称搜索先落地 | 保留 Claude 的效率增强方向，不扩张首轮闭环 |
| 多端隐私 | 桌面显示真实处理模式；能力不足不自动改为远程处理 | 对齐 V4.0，不将规划中的本地能力包装为已实现 |

Claude 文档中的“95% 时间停留在编辑器”等比例没有实测依据，本版不作为产品事实或验收指标。文中对同类产品的借鉴只用于设计选择；本版不承诺竞品同等功能，也不复制其套餐或限制。

### 1.2 落地原则

1. 核心对象唯一：Project 是可编辑项目，Artifact 是某一输入快照的成品。
2. 主要操作明确：页面级突出一个主操作，生成、试听、播放文案区分。
3. 不做伪成功：无接口不填假指标，无能力不显示可点击占位按钮。
4. 不丢用户编辑：保存失败、登录过期、冲突、切租户时均保护草稿。
5. 先增量更新：修改本页不默认重做全篇；无法局部重算时明确实际范围。
6. 权限从服务端来：前端可见性改善体验，后端继续校验每次操作。
7. 已实现能力优先接入；缺口按阻塞性决定补接口或延迟开放。

## 2. 范围与发布门槛

| 等级 | 范围 | 发布要求 |
|---|---|---|
| P0 核心闭环 | 正式/开发登录边界、租户上下文、项目管理、导入、三模式讲稿、保存、审阅与锁定、音色、本页试听、生成、任务反馈、播放、已支持导出 | 必须使用真实数据完成闭环，权限与版本语义通过验收 |
| P1 完整产品化 | 项目词典管理、增强冲突比较、全局成品聚合、准确首页统计、成员/额度/审计完整 UI | 已有对应接口则随 P0 接入；缺口不得伪装完成 |
| P2 可选增强 | 邮箱自助注册、域名发现、命令面板、复杂时间轴、多人实时协作、数字人、问答、公开分享 | 独立立项，能力与权限验证后开放 |
| 平台门控 | 桌面本地项目/隐私模式、移动端离线与后台播放 | 以平台实际能力验证为准，不单凭平台类型启用 |

P0 中“审阅”最低实现为逐页确认及锁定，不要求新增多人审批系统。权限矩阵规定哪些成员能批准；不以“已读过页面”代替正式确认状态。

## 3. 对象模型与术语

| 用户术语 | 对应对象 | 规则 |
|---|---|---|
| 讲解项目 | Project | 持续编辑入口，不因完成配音而离开项目列表 |
| 原始 PPT | SourceRevision | 不可变源文件版本；更新原文件创建新版本 |
| 页面 | Slide | 稳定 ID；展示原页码，排序不改变身份 |
| 讲稿 | ScriptRevision / Segment | 按页和分段保存；修改产生新修订 |
| 讲解版本 | 已确认输入集合/快照的产品展示 | 语言、音色、来源与讲稿修订关联；不凭前端计数编造版本号 |
| 配音 | AudioAsset + Alignment + TimelineRevision | 指向明确输入；修改后可失效但保留旧资产 |
| 生成任务 | Job / JobStep | 固定输入快照，不读取不断变化的“最新稿” |
| 成品 | Artifact | 不可变结果，记录格式、时间和快照 |

“可播放”表示存在可用讲解音轨和时间轴，不等于 MP4 已导出。“已完成”不单独作为所有对象共享状态。

如果后端尚无正式“讲解版本”实体，UI 用“生成记录 + 快照标识”呈现；不得在 localStorage 自建一套无法追溯的版本库。

## 4. 信息架构、Shell 与路由

### 4.1 默认导航

| 导航 | 内容 | 默认可见范围 |
|---|---|---|
| 首页 | 新建、继续编辑、待处理、近期完成 | 所有已认证成员，按资源权限过滤 |
| 讲解项目 | 全部/最近/归档、搜索与筛选 | 有项目读取权限者 |
| 任务中心 | 本人任务；有权限时切租户任务 | 按 job.read 权限与资源范围 |
| 设置 | 个人设置、租户设置 | 所有人可进个人设置；租户项单独授权 |
| 成品库（可选） | 跨项目成品聚合 | artifact.list 能力开放后加入 |

左侧品牌下显示当前租户名称；多租户成员点击切换，单租户只显示静态名称。系统内部仍叫 tenant，不再添加“工作空间”实体。

顶部包含面包屑、任务状态入口和用户菜单。用户菜单为“个人资料、偏好设置、退出登录”；角色与 ID 在个人资料查看，不持续显示 UUID。工作台使用独立 EditorShell，收起全局侧栏。

### 4.2 前端路由约定

以下为前端路由，不是新增 REST 接口；若现有路由不同，保留兼容重定向。

| 路由 | 页面 |
|---|---|
| /login | 登录 |
| /auth/callback | 已有认证回调，实际路径以部署为准 |
| /home | 创作首页 |
| /projects | 讲解项目；q/status/sort/cursor 放查询参数 |
| /projects/:projectId/editor | 工作台；slide/语言或已有版本标识放查询参数 |
| /projects/:projectId/artifacts | 项目成品与版本 |
| /projects/:projectId/settings | 项目配置、源文件及处理策略 |
| /artifacts/:artifactId/play | 固定成品播放器 |
| /jobs | 任务列表 |
| /jobs/:jobId | 任务详情，可直接链接并返回项目 |
| /settings/profile、/settings/preferences | 个人资料与偏好 |
| /settings/tenant/members、models、dictionary、usage、audit | 租户设置子路由，各后缀为独立页面 |
| /artifacts | 可选全局成品库 |

根路径：有云端会话进入首页，无会话进入登录。深链接先保存受信任站内目标，登录后验证访问权再返回。桌面本地模式使用显式本地入口及独立上下文，不要求为本地文件伪造云端身份。

### 4.3 权限与切租户

前端能力检查同时用于导航、按钮、路由守卫。服务端负责最终授权；用户输入或 URL 中的 tenantId 不能决定访问权。

切租户顺序：检查未保存稿 → 保存成功或用户明确处置 → 停止当前播放与订阅 → 取消旧上下文请求 → 清理/隔离旧缓存 → 建立新成员上下文 → 跳到新租户首页。旧租户任务继续在服务端执行，不自动取消。迟到响应按上下文标识丢弃。

缓存键包含 tenantId、用户/会话作用域、资源 ID 和相关版本；退出登录后清除敏感查询缓存。草稿隔离到用户+租户+项目，不允许下个登录账号自动看到上个账号的草稿。

## 5. 登录、首次使用与账号

### 5.1 页面规格

宽屏左侧展示品牌及产品示意，右侧登录卡；窄屏只保留品牌和登录卡。主文案：“让每一页 PPT，都有清晰的讲解”。不将 AI 模型名、租户 UUID 或 token 状态作为营销内容。

| 部署场景 | 入口与行为 |
|---|---|
| 已配置企业认证 | 显示“企业账号登录”，调用已有认证流程 |
| 显式开发环境 | 显示 DEV 标识与“开发身份进入”；可预填现有测试 ID |
| 正式环境未配置认证 | 显示“登录服务尚未配置，请联系管理员”，不回退到开发身份 |
| 已有账号体系支持个人登录 | 复用该体系，不为本轮另写一套认证 |
| 未来自助注册 | 有后端注册、验证、成员建立与额度规则后显示入口 |

开发身份必须前后端同时开启。前端写 localStorage 不构成身份认证。企业与个人认证可由现有身份提供方统一承载；邮箱发现、多租户选择属于后续能力，不默认按邮箱域名授予成员资格。

登录按钮防重复提交；回调失败提供重试；401 引导重新认证，403 显示无权访问而非无限跳登录。登录成功后按服务端成员信息选择租户：一项自动进入，多项显示可搜索的租户选择。

### 5.2 首次空状态

无项目时：首页显示一句引导、三步说明、唯一主按钮“导入第一份 PPT”。可提供明确标识的样例入口，样例不计入真实用户统计，也不预写假任务。

服务尚未配置：管理员看到“配置语音服务”，普通用户看到“语音生成暂不可用，请联系管理员”；若导入和编辑仍可用，则保留这些操作，不整页阻塞。

## 6. 首页与项目列表

### 6.1 首页布局

1. 顶部欢迎与“新建讲解”。
2. 最近编辑项目 4～6 项，优先占据首屏。
3. 待处理事项：讲稿待确认、音频需更新、失败任务，可跳到具体页。
4. 紧凑统计：项目总数、可播放项目/成品数量、进行中任务；精确标签区分计数对象。
5. 最近完成成品及必要的管理员配置提醒。

未取得聚合接口时展示真实最近列表，统计卡隐藏或标“暂无统计”。分页 List 的本页长度不能作为总数；网络失败不能显示为 0。用量必须带周期和单位，存储必须标统计时间。

### 6.2 项目列表

默认封面卡片，支持表格视图并记忆个人偏好。卡片展示封面、名称、页数、修改时间、当前处理提示和成品数量（有准确字段时）。提供名称搜索、状态筛选、排序；筛选条件写 URL。未提供全量搜索接口时必须标明“搜索当前已加载项目”。

点击名称/封面直接进入工作台。主操作按当前状态显示“创建讲稿、审阅讲稿、继续编辑、更新配音”；成品播放作为独立快捷操作。更多菜单含重命名、查看成品、项目设置、归档；复制/删除仅在实际接口存在时显示。

归档不等于删除；有归档能力就使用归档，不将 Archive 包装成彻底删除。永久删除需展示影响范围，包括源文件和成品，处理进行中任务按服务端策略决定。

### 6.3 全局反馈

加载用骨架；空列表区分无项目与筛选无结果；单模块失败不覆盖整页。成功提示短暂出现，失败、保存冲突和额度问题保留可操作入口。技术错误码放“查看详情”，普通文案直接说明受影响动作。

## 7. 导入与解析

“新建讲解”打开导入弹窗/独立窄屏页面，提供拖放和选文件。显示服务端实际支持的格式、大小和页数限制；V4.0 的 100 页/100 MiB 是可配置保护建议，不能硬编码为所有部署限制。

| 阶段 | 显示 | 操作 |
|---|---|---|
| 选文件 | 文件名、大小、处理位置、格式限制 | 更换、开始导入 |
| 上传中 | 已传字节与真实百分比 | 有能力时取消/续传 |
| 校验与解析 | 当前阶段；未知进度用不定进度条 | 查看任务 |
| 页面陆续可用 | 已处理页数、可用缩略图 | 进入工作台查看已就绪页 |
| 完成/部分异常 | 总页数、备注页数、隐藏页、兼容性问题 | 定位异常页、继续编辑 |

CreateUpload → 上传文件 → CompleteUpload → 查询解析任务。CompleteUpload 未成功前不宣称导入完成；重试按接口幂等约定恢复，避免重复建项目。

导入后的“讲解设置”使用非阻塞面板：讲稿模式、受众、风格、语言、目标时长和音色。默认优先使用备注；缺少备注的页提示选择正文朗读或 AI 生成，不在原文朗读模式下自动改成 AI 改写。

隐藏页默认不纳入讲解，可显式添加；封面和无稿页允许静默停留，标注时长。解析报告按页展示字体替换、嵌入媒体和动画限制。允许继续时说明实际输出，不将保留动画 XML 等同于动画可播放。

## 8. 创作工作台详细规格

### 8.1 布局和组件

| 区域 | 默认内容 | 行为 |
|---|---|---|
| EditorHeader | 返回、名称、保存状态、语言/版本、任务状态、预览、生成、导出 | 当前主要阶段突出一个主按钮；其他为次级 |
| SlideNavigator | 缩略图、页码、状态、时长 | 点击定位；筛选异常/待确认/需更新；支持键盘上下切换 |
| SlidePreview | 页面渲染图、缩放、来源定位 | 保持原比例；不提供未支持的 PPT 元素编辑手柄 |
| ScriptPanel | 分段讲稿、模式、确认/锁定、AI 建议 | 主编辑区域；发音操作紧邻文本 |
| PropertiesPanel | 音色、语速、目标时长、来源详情 | 与讲稿页签切换或抽屉展开，不固定第四栏 |
| PlaybackBar | 本页/全篇、播放暂停、进度、倍速、字幕 | 固定底部；进度来自实际媒体时钟 |

1440px 参考尺寸：顶部 56px；左栏 200px（可调 160～280）；右栏 400px（可调 360～520）；中间自适应；播放条约 64px。低于 1200px 收起属性、缩略图可折叠，避免预览不足。尺寸为设计 token 起点，实际按内容和可访问性验证。

### 8.2 讲稿模式

| 模式 | 输入与结果 | 约束 |
|---|---|---|
| 原文朗读 | 用户选定备注或正文 | 不做语义改写，读音规范化与显示文字分离 |
| 润色讲解 | 基于已有稿生成建议 | 对照接受/拒绝，不直接替换已审核稿 |
| AI 生成讲解 | 基于页面结构与图像等实际可用输入生成草稿 | 关键事实可查看来源，未核实内容标待确认 |

AI 操作范围必须显示为选中段、当前页、选中页或全篇；默认当前页。再次生成跳过锁定稿和已审核稿；如需修改已审核内容，由用户显式进入修改流程，创建新草稿并重新确认。

段落选中工具栏：缩短、润色、补充衔接、发音、停顿；强调/情绪等控件按当前音色能力开放。不要求用户填写 SSML、模型 ID 或编解码参数。

来源以可点击标记定位到当前页对象；缺少对象坐标则显示页码和原文摘录，不绘制虚假精确高亮。默认不引入 PPT 之外的事实。

### 8.3 读音与音色

选中词语后打开“调整读音”：显示文字、读法、试听、作用范围。范围为本处/本项目；有权限时可保存到租户词典。项目规则覆盖租户规则；更新规则后后端返回或计算受影响段，UI 展示更新数量，不擅自承诺全部缓存命中。

音色选择器：按语言、风格等已返回属性筛选；先播放样例再应用。项目默认音色与单页覆盖分开显示，恢复默认清晰可见。全篇换音色前列出影响范围和估算用量。

三类按钮严格区分：“试听音色样例”“生成本页试听”“播放已有音频”。试听可能消耗生成额度，按真实策略提示；正式生成不因试听名义而绕过用量规则。

### 8.4 保存、冲突与恢复

建议文本停止输入约 800ms 后保存，页面切换时刷新待保存队列；中文输入法组合期间不提交半成品。显示未保存、保存中、已保存、失败和冲突。

保存请求携带 expected_revision（映射实际契约）。同页写请求有序提交，忽略旧响应对新草稿的覆盖。冲突时保留本地稿，展示服务端新稿，可复制本地内容并逐项合并；未决冲突不允许“生成最新稿”。第一轮可先用简单对照弹窗，无需开发复杂差异编辑器。

手动保存使用 Ctrl/Cmd+S。离开页面、刷新、退出、切租户时，如草稿未安全保存，提示保存/留在此页/明确放弃。云端草稿的本地恢复副本按租户策略启用，设置保留期限；不将浏览器临时缓存宣传为完整离线模式。

### 8.5 生成与导出前置检查

生成面板显示范围、语言、音色、待确认稿数量、需要新生成/可复用部分、预计时长和用量。目标时长是估算，实际时长以音频为准；没有价格接口则只展示可确认的单位量，不编造费用。

正式生成以已确认快照为输入；默认阻止未确认稿直接进入正式生成，可提供“审阅并确认选中页”，不在后台自动批准。生成中继续编辑允许进入后续草稿，顶部提示“本次生成使用提交时版本”。

按钮提交后进入 pending，收到 jobId 后关联现有任务；网络结果不明时先查询/按幂等键恢复，不直接创建第二个任务。

## 9. 状态模型与增量更新

### 9.1 状态分层

| 对象 | UI 状态示例 | 说明 |
|---|---|---|
| 解析 | 上传中、解析中、可用、部分异常、失败 | 部分异常不抹去可用页 |
| 讲稿 | 空、草稿、待确认、已确认 | 锁定是独立属性，不能与确认混为一谈 |
| 配音 | 未生成、排队、生成中、可播放、需更新、失败 | “需更新”由当前输入与音频关联修订比较得出 |
| 任务 | 排队、处理中、正在取消、已取消、成功、失败 | 使用后端枚举映射；未知状态显示“状态更新中”并刷新 |
| 成品 | 可用、不可用/已清理 | 草稿更新不改变旧成品是否有效，只提示有新草稿 |

### 9.2 修改影响

| 改动 | UI 反馈 | 重做范围 |
|---|---|---|
| 修改一个分段 | 本段/本页“音频需更新” | 相关 TTS、对齐、页/全篇时间轴及需要的合成 |
| 修改整篇音色 | 显示受影响页数 | 受影响音频及对齐；页面图复用 |
| 修改字幕样式 | 提示需要重新导出 | 烧录视频/样式产物，不默认重做 TTS |
| 调整页序 | 提示顺序改变、衔接待复核 | 时间轴与合成，原音频可复用 |
| 更新源 PPT | 显示新源版本与受影响页 | 依赖实际页面匹配结果，无法匹配时不猜测继承 |

示例文案：“第 6 页讲稿已保存，已有音频尚未更新。”操作：“更新本页配音”“播放已有音频”。旧音频播放时带“此前版本”标记。

## 10. 任务中心与实时反馈

任务列表列：项目、类型、提交时间、范围、阶段、进度、状态、操作。详情包含步骤、受影响页、输入版本、开始/结束时间、可操作错误与详情 traceId。创建者仅在授权范围内可见。

优先接已有 WatchEvents；否则活跃页面建议每 2～3 秒轮询，后台页面降低频率，例如 10～15 秒；遇限流遵守 retry_after 并退避。这是客户端默认建议，不是服务端 SLA。已有流断开时回退轮询，重连按事件序号续接；序号过期拉全量。

| 场景 | 正确反馈 |
|---|---|
| 无总工作量 | 阶段文案与不定进度条，不估造 80% |
| 有完成页数 | “语音生成 8/20 页”；说明这是页数进度，不是总耗时预测 |
| 部分页失败 | 展示失败页与“重试失败部分”；已有成功结果保留 |
| 点击取消 | 先“正在取消”，服务端确认后“已取消” |
| 关闭页面 | 服务端任务继续；再次进入恢复显示 |
| 完成 | 站内提示及播放/下载入口，不强制跳转打断编辑 |
| 供应商结果未知 | 显示“正在核实生成结果”，不开放无约束重复提交 |
| 鉴权或永久格式错误 | 给修复入口，不展示无意义自动重试 |

桌面通知为用户主动开启的可选能力，不以拒绝通知权限阻断任务。重试和取消按钮按服务端允许动作显示；接口未提供取消时明确不能取消，列为闭环缺口，不做前端假取消。

## 11. 成品、播放器与导出

项目“成品与版本”按生成快照分组，组内列 MP4、音频包、字幕等产物；显示版本/记录标识、源文件版本、语言、音色、实际时长和时间。成品与项目间双向跳转。仅实际产物存在且可访问时显示下载。

播放器固定指向成品快照，不跟随当前草稿变化。提供播放/暂停、进度拖动、上/下页、目录、倍速、字幕、全屏。音频时间是切页依据；缓冲和加载失败显示状态，恢复播放不重置到第一页。尚未完成的全篇不提供看似完整的成品播放；编辑器可明确播放已就绪页。

| 导出类型 | 控件与边界 |
|---|---|
| 静态页面 MP4 | 原始比例、实际支持的分辨率、字幕烧录选项；标明静态页面 |
| 音频 | 按真实接口提供整篇或逐页及格式 |
| 字幕 | SRT/VTT，以真实对齐数据生成 |
| 配音 PPTX | 仅能力门禁通过后显示；说明认证播放器与动画限制 |

导出创建新任务并绑定快照。当前草稿与可用音频不一致时，提供“先更新配音”或明确导出“此前已完成版本”，不能混合新字幕与旧音频。下载链接过期可重新申请。公开分享默认不开启；邀请、有效期和撤销必须有真实授权能力后独立上线。

## 12. 设置与权限矩阵

个人设置：资料、界面语言、显示密度、通知偏好；只显示能保存生效的配置。租户设置：成员与权限、模型服务、发音词典、用量与存储、审计。不存在独立“用户管理全平台账号”权限时将其命名为“成员管理”。

以下为推荐默认角色映射，联调时以服务端 policy 为权威。所有“允许”仍限授权项目/对象，角色不自动获得所有租户数据。

| 动作 | Owner | Admin | Editor | Reviewer | Viewer |
|---|---|---|---|---|---|
| 查看授权项目/播放 | 允许 | 允许 | 允许 | 允许 | 允许 |
| 创建、编辑、生成 | 允许 | 允许 | 允许 | 否 | 否 |
| 确认讲稿、锁定 | 允许 | 允许 | 按策略 | 允许 | 否 |
| 导出/下载 | 按策略 | 按策略 | 按策略 | 按策略 | 按策略 |
| 修改项目词典 | 允许 | 允许 | 允许 | 否 | 否 |
| 管理租户词典/模型/成员 | 允许 | 允许 | 否 | 否 | 否 |
| 看租户审计和用量 | 允许 | 允许 | 否 | 否 | 否 |
| 转移所有权/删除租户 | 允许且接口支持 | 否 | 否 | 否 | 否 |

UI 不通过角色字符串散落判断，统一转换为服务端授权能力。Reviewer 可读讲稿并确认，但不直接改写；需要建议稿/评论接口才提供相应功能。

模型服务页区分“已配置”“连通性检测通过”“当前不可用”，列表存在不代表健康。用户侧文案为“讲稿生成暂不可用”或“语音服务尚未就绪”；管理员详情可看到供应商、检测时间与诊断。模拟供应商环境明确显示“演示模式，非正式语音结果”，不得将模拟结果作为正式成品。

## 13. 多端、离线与处理位置

| 平台 | 导航与工作台 | 能力边界 |
|---|---|---|
| Web | 完整三栏，宽度不足时抽屉化 | 当前实现使用服务端处理，上传前明确说明 |
| 桌面 Tauri | 完整工作台，入口区分云端与本地项目 | 本地引擎、模型和导出能力实际就绪后启用 |
| 移动 Tauri/Web | 首页/项目/任务/我的；编辑用页面与讲稿切换、底部播放器 | 轻编辑与审阅优先，复杂时间轴不直接缩小移植 |

断点建议：≥1200px 完整三栏；768～1199px 缩略图抽屉、两区切换；<768px 单列与底部操作。实际按内容容纳能力调整，不以设备品牌判断。

处理模式以项目为单位可见。桌面隐私模式最低语义为项目内容不送远程处理；缺少本地 LLM 时可保留手工稿，缺少本地 TTS 时禁用生成并提供能力安装入口。切换到云端由用户显式操作，并说明传输范围；不后台回退。若后端定义不同的“源文件不上传但文本远程处理”策略，必须另行命名并明确边界。

仅有缓存播放叫“已下载，可离线播放”；仅能暂存修改叫“离线草稿”；不能统一叫“完整离线”。退出和切账号后本地文件访问按本地权限与项目作用域隔离。删除源文件前提示重新解析、配音 PPTX 写出等实际受影响功能。

| 项目 | 设计基线 |
|---|---|
| 色彩 | 浅灰工作区、白色内容面板、单一蓝紫主色；PPT 内容保持中心 |

## 15. 接口衔接与前端工程组织

### 15.1 契约核对表

下表中的能力需求是 UI 最低输入，具体字段采用实际生成客户端；不要求把已有 RPC 重写成 REST。

| UI 能力 | V4.0 对应服务 | 联调必须确认的数据/动作 | 缺口处理 |
|---|---|---|---|
| 会话、租户与权限 | 现有认证、TenantService | 当前用户、成员租户、允许动作、退出行为 | P0 阻塞；不得由前端假设 Owner |
| 项目列表/详情 | ProjectService | 分页、名称、页数、来源修订、读取范围 | 无总数则隐藏总数指标 |
| 上传解析 | UploadService + JobService | 上传/完成/中止、任务 ID、解析报告 | P0 联调，禁止前端假解析成功 |
| 讲稿保存审核 | ScriptService | revision、更新、确认、锁定、冲突 | P0；简单冲突对照足够 |
| 估算与配音 | NarrationService | Estimate、生成、局部重生成、快照关联 | 局部不支持则明确实际重做范围 |
| 音色/供应商能力 | 已有模型服务接口 | 音色样例、语言、可用参数、服务状态 | 名称/结构由实际接口适配 |
| 任务 | JobService | Get/List/Cancel/RetryFailed、可重试性、阶段 | 流可轮询替代；取消不能假实现 |
| 播放与导出 | ExportService 及实际媒体接口 | 时间轴、音频/字幕授权地址、Artifact、下载 | P0 验证固定快照与地址续期 |
| 成品列表 | 实际项目产物查询 | 项目/快照/格式/时间/可用性 | 无聚合接口则只显示项目内产物 |
| 成员/用量/词典 | TenantService 与已有词典接口 | 写权限、周期、单位、规则作用域 | 逐项开放，不填占位数据 |
| 首页摘要 | 可选聚合能力 | 总数、待办数、统计时间 | 非 P0 阻塞，不遍历全量分页强算 |

V4.0 未列出所有会话、音色、词典和产物列表的具体操作。实施时先导出真实契约清单，记录“已可用/字段适配/需补接口/暂不开放”，由该表驱动页面能力。

### 15.2 UI 视图模型（建议，不是服务端协议）

```ts
type CapabilityState = 'available' | 'unavailable' | 'unknown';
type SaveState = 'clean' | 'dirty' | 'saving' | 'error' | 'conflict';

interface EditorViewModel {
  contextKey: string; // 用户、租户/本地作用域、项目
  projectId: string;
  slideId: string;
  scriptRevision: string; // 适配实际 revision 类型，避免大整数精度丢失
  saveState: SaveState;
  scriptStatus: 'empty' | 'draft' | 'pending_review' | 'approved';
  locked: boolean;
  audioState: 'missing' | 'queued' | 'running' | 'ready' | 'stale' | 'failed';
  permissions: string[]; // 由服务端权限映射
  capabilities: Record<string, CapabilityState>;
  activeJobId?: string;
}
```

unknown 不等于可用；配置项加载失败时保留内容查看，禁用依赖该能力的提交并给重试。状态映射集中维护，禁止组件自行猜测服务端枚举。

### 15.3 组件与状态分工

- Shell：AppShell、EditorShell、TenantSwitcher、UserMenu、TaskIndicator。
- 项目：ProjectList、ProjectCard、ImportDialog、ImportReport。
- 编辑：SlideNavigator、SlidePreview、ScriptEditor、SuggestionDiff、VoicePicker、PronunciationPopover、GenerationDialog、ConflictDialog。
- 媒体：PlaybackBar、ArtifactPlayer、ExportDialog、ArtifactList。
- 管理：PermissionBoundary、SettingsLayout、JobDetail、UsagePanel。

沿用 React + TypeScript + Vite、生成 Connect 客户端及现有组件库。服务端查询缓存、未提交编辑状态、播放器状态分别管理；文件/播放/通知由 PlatformAdapter 提供。若已有组件库不更换，不因本轮 UI 调整同时重构技术栈。

API proxy 问题作为联调前置：确认开发代理目标、路径重写、认证传递及响应类型，避免把 SPA HTML 回退解析为 JSON。只记录排查所需状态码与响应类型，不把 token 输出到日志。以实际 Connect 请求为验证对象，不虚构 /api/dashboard/summary 必须存在。

## 16. 实施批次与交付物

不按“后端全部完成”推断前端无接口缺口，也不重新启动后端大改造。以下按依赖顺序实施，具体工期由接口差异表与现有前端代码量确认。

| 批次 | 任务 | 可交付物 | 出口条件 |
|---|---|---|---|
| B0 联调基线 | 梳理契约、代理、认证、能力、状态映射 | 接口差异表、能力表、真实样例数据 | 可登录、列项目、读取一个项目及任务 |
| B1 框架与导入 | Shell、路由、租户作用域、首页空态、项目列表、上传报告 | 可操作导航和真实导入 | 刷新深链接可恢复；权限不越界 |
| B2 核心创作 | 三栏、讲稿模式、保存、确认锁定、音色、本页试听 | 一份真实 PPT 的连续编辑闭环 | 不覆盖已确认稿；保存失败不丢输入 |
| B3 生成与交付 | 固定快照、任务轮询/流、失败恢复、播放器、导出、项目成品 | 完整讲解成品 | 可重进恢复；旧成品与新稿区分 |
| B4 管理与适配 | 已有成员/用量/词典/审计、移动布局、实际桌面能力 | 权限完整的产品 UI | 按平台和角色通过验收 |
| B5 可选增强 | 全局成品、命令面板、自助注册等 | 独立增量功能 | 需求成立、接口和权限齐备 |

UI 设计交付至少包括：常规首页/首次空态、项目卡片/表格、导入全过程、工作台正常/冲突/需更新/局部失败、生成确认、任务列表/详情、播放器/导出、个人与租户设置、移动端工作台。所有按钮标明动作、输入、成功状态、失败状态及所需权限，不能只有静态视觉稿。

| A04 | 分页统计 | 只拿到一页项目时不显示其长度为总数 |
| A05 | 深链接登录 | 登录后回到有权访问的项目；无权项目显示拒绝 |
| A06 | 切租户、迟到响应 | 不显示旧租户项目、音频或草稿；旧任务不被误取消 |
| A07 | 导入部分失败 | 可查看成功页；异常报告可定位；不宣称全成功 |
| A08 | 原文朗读 | 不自动改写；无备注时显式选择来源 |
| A09 | AI 再生成 | 已确认/锁定内容不被静默覆盖 |
| A10 | 快速输入与中文输入法 | 不提交半个组合文本；旧响应不回写新稿 |
| A11 | 保存失败/401 | 用户输入保留，恢复登录/网络后可继续保存 |
| A12 | 两端同页修改 | revision 冲突可见，本地稿可恢复，不最后写入覆盖 |
| A13 | 发音修改 | 正常字幕保留；仅声明并更新受影响范围 |
| A14 | 修改单页后播放 | 显示音频需更新，旧音频标此前版本 |
| A15 | 生成中继续编辑 | 当前任务保持原输入，后续草稿不混入结果 |
| A16 | 重复点击/网络结果未知 | 使用原任务/幂等恢复，不造成 UI 发起重复生成 |
| A17 | 任务取消 | 请求与完成状态区分；刷新后与服务端一致 |
| A18 | 局部失败重试 | 成功部分保留，只重做实际允许范围 |
| A19 | 事件断开/刷新 | 重新查询恢复，未知阶段不伪造百分比 |
| A20 | 导出与成品 | 成品绑定快照；新讲稿不搭配旧音频误导输出 |
| A21 | 音频同步 | 跳页、暂停、倍速以实际时钟同步；长片指标沿用 V4.0 实测门槛 |
| A22 | 权限 | Viewer/Reviewer 不能通过直接 URL 或请求越权修改；菜单与后端一致 |
| A23 | 模拟/未配置服务 | 不输出伪正式成品；提示作用与修复入口准确 |
| A24 | 桌面隐私模式 | 无本地能力时不静默远程调用；项目内容边界可验证 |
| A25 | 移动与键盘 | 无横向挤压；可完成单页审阅/试听；文本输入不被空格播放抢占 |
| A26 | 无接口功能 | 隐藏或明确不可用，无可点击的假保存/假导出 |

验收使用真实 PPT、真实正式 TTS 和真实异步任务；测试数据覆盖备注完整、无备注、隐藏页、字体异常、中英术语、长稿及局部失败。模拟数据仅用于组件状态展示，需明确标注，不作为功能验收证据。
