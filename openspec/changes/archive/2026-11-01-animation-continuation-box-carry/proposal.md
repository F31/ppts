# 跨页延续的静态盒补偿（G8 边界③）

## 为什么

G8 主变更解决了「动效跨页不中断」：负起点让 clip 进度在页缝两侧逐位相等。但成片里还有一类
瑕疵它管不到——**元素跳一格**。

原因很简单：延续段落在次页的层上，而层的静态盒（`box.x/y/w/h`）是作者按那一页的版式摆的。
只要同一元素在相邻页的盒不同（挪了位置、改了尺寸），页缝处就会出现一个**纯几何**的跳变：
动效进度完全连续，画面却瞬移了一段。所有既有判据都看不见它——求值连续性比的是 `tx/ty/sx/sy`，
末帧比对又不含延续元素。

当前的实际约束是「作者必须自己在相邻页把元素摆在同一位置」，文档里写成约定，但没有任何东西
检查它。作者一旦为了版式挪动元素，页面就悄悄坏掉——不报错、不崩，只是看起来不对。

## 做什么

编译器在每次注入延续段时顺带检查相邻两页的盒：

- 盒相同 → 什么都不做（清单与今天逐字节一致，这是硬要求）；
- 盒不同 → 给续播层补一条 `carry = true` 的补偿段，用 `translate` + `scale` 把该层从上一页的
  盒「搬」回本页的盒，并在 500ms 内收敛到恒等变换。

补偿量不是简单的位置差，必须含锚点项：

```
sx = prev.w / next.w,  sy = prev.h / next.h
tx = (prev.x - next.x) - Ox·(1 - sx)
ty = (prev.y - next.y) - Oy·(1 - sy)
```

`Ox/Oy` 是本页层锚点在层内的局部偏移。缺了 `O·(1-s)`，凡锚点不在左上角且尺寸有变化的延续都会
在页缝偏一段（center 锚点、缩到 0.8 时偏 10% 的尺寸）。

**为什么放在编译器而不是播放器**：清单因此自描述，播放器与渲染器零改动就能得到正确结果——
它们本来就把 `props` 当普通属性轨道求值。放在播放器则要改两处，还会让「包本身是否自洽」无法
被离线校验。

## 边界

- **只补盒差，不补内容**。同一 `elementId` 在不同页换了图案/颜色，属于「换了元素」而不是
  「同一元素在动」，无法也不应插值。
- **不做像素级验收**。门禁比的是清单里的视觉矩形（`box` 叠加 `transform`），不是截图像素；
  画得对不对由 V13/V13b 各自守。
- **降级动画（reduced motion）下不补偿**。播放器在 `reduceMotion` 时本就把 `tx/ty/sx/sy` 归零，
  补偿随之失效；这是刻意的——用户要求「不要动」，就不该合成一段滑移。页切换本身是硬切，
  元素在不同页出现在不同位置并不违反该偏好。
- **宽高比不一致时会出现非等比拉伸**。补偿用 `scaleX`/`scaleY` 独立插值，盒形在整个收敛窗口内
  从上一页的盒线性变到本页的盒。这是「盒必须重合」的精确解；若两侧宽高比差得离谱，观感会是
  一次形变。此类编排本身就意味着元素在两个页面上不是同一个形状，作者应改用两个元素。
- **链式（>2 页）每跳单独补偿**。参照是上一跳所在页的盒，不是源页的盒。
