# Spec Delta

## Purpose

定义「HTML 成品包」在交付前必须通过的质量判据：自包含（V14）、体积预算（V15）、真实浏览器可播放（V16）、四条降级路径可用（V17）、画面与源页一致（V13b）、两端画得一样（V13）、页内切图真的发生（V18）。目标是让「包有没有坏」变成一条可执行的命令，而不是靠人打开看一眼——外链、体积翻倍、资源 404、降级失效、画面画错、两端分叉、切镜没切这七类问题在导出时都不会报警，只会在客户打开时暴露。

## MODIFIED Requirements

### Requirement: 终态帧与源页一致

成品包在每一页的取样时刻画出来的那一帧，MUST 与**这一帧该有的参照图**一致。参照图不是随手取的一张：无页内镜头时是源页图；有页内镜头时，末镜 `crop` 为空取源页图（此刻层仍可见，镜头图只是底板），`crop` 非空取包内那张镜头图（此刻层被隐藏，画面就是它）。

判据 MUST 同时满足三条：SSIM ≥ 0.995、平均差 ≤ 0.5、差 >32 的像素占比 ≤ 0.05%。三条不是三个宽松近似，而是同一条等式的三种投影：平均差抓整体色偏，结构性差异占比抓局部错位，SSIM 抓纹理与边缘。判据 MUST NOT 依赖渲染服务或成片——只需要一个浏览器。

取样 MUST 落在该页最后一个镜头内、且避开叠化窗口：取「末镜起点 + `crossFadeMs` + 1 帧」与「页尾前 250ms」中更靠后的一个，并夹在末镜之内。理由是末镜可能比 250ms 还短（页尾前 250ms 会落到上一镜），而中点又可能落在叠化里（120ms 叠化 + 100ms 镜头）。门禁 MUST 把实际落点读回来与请求比对：偏差 >50ms 即判失败，而不是拿一张拍错时刻的图去比。

参照图与舞台尺寸不同时（特写图是原页的一块，宽高比通常与画布不同），参照图 MUST 先缩放到舞台尺寸，并 MUST 换一组阈值（SSIM ≥ 0.99、平均差 ≤ 1.0、结构差异仍 ≤ 0.05%），MUST 在报告里标注该页是「参照图缩放」。实测该情形下正例 0.9972 / 0.49，右移 40px 掉到 0.9497 / 3.66，拿整页图当参照掉到 0.6900——三档拉得开，不是随手放宽。

末镜换了整页图、而这一页又带元素动画时，画面是「镜头图 + 层」，包里没有可比的无层参照图：这类页 MUST 报 skip 并写明原因，MUST NOT 拿残图去比、MUST NOT 计入通过。skip 不影响退出码，但 MUST 在报告里出现——静默通过的页会让人以为它被验过。

#### Scenario: 正常的包

- **WHEN** 用 `share-baseline -width 1280 -height 720 -layers 2 -pages-out` 造包并跑门禁
- **THEN** 每页 SSIM ≈ 0.9999、平均差 ≈ 0.002、结构性差异 0.000%，门禁通过

#### Scenario: 末帧是特写

- **WHEN** 用 `-shots 2` 造包（末镜 `crop` 非空），层在该镜内被隐藏
- **THEN** 取样落在末镜内且避开叠化，参照物是包内镜头图，SSIM ≈ 0.99994

#### Scenario: 特写图比舞台小

- **WHEN** 末镜图是 640×360，舞台是 1280×720
- **THEN** 参照图 MUST 缩放到 1280×720 后比对，报告 MUST 标注「参照图缩放」，阈值换成 0.99 / 1.0 / 0.05%

#### Scenario: 图层框错位

- **WHEN** 把清单里某个图层的 `box.x` 右移 40px（层图随之错位，页图上露出未覆盖的空洞）
- **THEN** 该页结构性差异 0.52% > 0.05%，门禁失败并指出是哪一页、哪条指标

#### Scenario: 底板颜色偏了

- **WHEN** 把包内底板 PNG 的每个通道 +10
- **THEN** SSIM 0.960 < 0.995 且平均差 9.6 > 0.5，门禁失败

#### Scenario: 定位失效

- **WHEN** 播放器的定位接口被改坏，实际落点与请求相差 >50ms
- **THEN** 该页判失败，报文指出是定位问题；MUST NOT 继续拿错帧比对

#### Scenario: 末镜换图且该页有元素动画

- **WHEN** 末镜的 `image` 不是页级图、`crop` 为空、该页 `layers` 非空
- **THEN** 该页 MUST 报 skip 并说明「画面 = 镜头图 + 层，包里没有可比的无层参照图」，退出码不受影响

### Requirement: 两端同帧一致（V13）可在没有渲染镜像的环境里验证

成品包在某一时刻画出来的画面，MUST 与成片同一时刻的解码帧一致。取样 MUST 同时包含**动画进行中**的时刻（第一段 clip 的中点）与页首、页尾；只看末帧会在动画早已结束的静态页上拿到 0.99，什么都没验。

页内声明了镜头切片时，取样 MUST 另含**每个切点之后**的时刻，取 `startMs + crossFadeMs + 1 帧`。不取切点本身：混合窗口只有 120ms，两端时钟差 20ms 就会让同一时刻的颜色不同，那个差会被记成「两端不一致」，其实只是取样时刻不同。

判定 MUST 用逐页最差帧：一页里任一取样点不达标即判该页失败，MUST NOT 用全片平均盖过单页的失败。

这条判据 MUST 只依赖「一个浏览器 + ffmpeg」，MUST NOT 要求渲染镜像或 docker。为此它 MUST 能从**成品包自身**造出可复现的分段（逐帧截 DOM → 编码），并把「夹具能证明什么」写清楚：它证明截图落点、抽帧、解码与阈值这条管线，**不证明**包与真实渲染一致。

门禁 MUST 在材料不齐时以退出码 2 结束（缺分段、时间轴与包不是同一画布、舞台取不到），MUST NOT 拿缩放或错帧照常判。

#### Scenario: 夹具正例

- **WHEN** 用 `make-fixture.mjs` 造 2 页 / 2 秒的分段（`--shots 2`），再跑 `dom-ssim.py`
- **THEN** 逐页最差帧 MUST ≥ 0.95（实测 0.99646–0.99772，退化为编码损失），退出码 0

#### Scenario: 成片错位

- **WHEN** 把某一页的分段整体左移 40px 后重跑
- **THEN** 该页 MUST 判失败（实测 0.932），其余页不受影响，退出码 1

#### Scenario: 材料不齐

- **WHEN** 缺一页分段，或时间轴画布与包的画布不一致
- **THEN** 门禁 MUST 以退出码 2 结束并在开浏览器之前报出原因

#### Scenario: 切点两侧的取样

- **WHEN** 页时长 2000ms、第二镜 `startMs=1000, crossFadeMs=120`、fps=30
- **THEN** 该页的取样点 MUST 含 1153ms（切点后一帧），且该页最差帧不得低于阈值

## ADDED Requirements

### Requirement: 页内切图在正确时刻发生（V18）

声明了页内镜头的包，MUST 在清单写明的时刻真的换图。对每一页里每个 `k>0` 的镜头，判据 MUST 覆盖切点前后各一帧（主图分别是第 `k-1`、`k` 镜那张图，且不透明度 ≥0.95）、叠化中点（两张图在场，淡入的那张不透明度在 0.05–0.95 之间），以及两条跨点约束：

- 同一页的几次取样之间，层节点的身份 MUST 不变（该页有层时才检）——重建会让元素重新入场，而 `clips` 是页内相对时间，重建一次整页动画就重播一遍。
- 每个取样点上层的可见性 MUST 与「这一镜是不是特写」一致：`crop` 非空的镜头里层 MUST NOT 显示，整页镜里 MUST 显示。

它与 V13b 的分工 MUST 写清：V13b 只看末镜那一帧，把「切镜」整个删掉、只留末镜图，V13b 照样过——而「一页多镜」存在的全部证据就是中间那次切换。

#### Scenario: 正常的两镜页

- **WHEN** 页时长 4000ms，两镜各 2000ms，第二镜 `crossFadeMs=120`、`crop` 非空
- **THEN** 1967ms 主图是首镜图、2060ms 两张图在场且淡入的那张 0.88、2153ms 主图是特写图；层节点身份三次一致；特写镜内层不可见

#### Scenario: 主图取哪一张

- **WHEN** 叠化进行到一半，底层是旧镜（不透明度 1）、顶层是新镜（0.88）
- **THEN** 「主图」MUST 取不透明度最高的那张（旧镜），`fade` 点 MUST 单独按「淡入的那张」判；MUST NOT 用同一个「最高」规则去判淡入，否则会把「根本没淡入」判成通过

#### Scenario: 落点没取准

- **WHEN** 总时长 40 分钟、播放器没有微秒定位接口，滑杆一步就是 2.4 秒
- **THEN** 落点偏差 >5ms MUST 判失败，报文 MUST 写明定位走的是滑杆还是微秒接口；MUST NOT 把「没取准」记成「切错了」

#### Scenario: 播放器不认镜头（降级形态）

- **WHEN** 清单带 `shots`，但包里的播放器是引入镜头之前的版本（只认 `slide.image`）
- **THEN** 切点后的取样 MUST 失败并指出主图是首镜图，退出码 1；这条正是 V13b 抓不到的那一类

#### Scenario: 层被重建

- **WHEN** 切镜时错误地调用了 `rebuildLayers`
- **THEN** 同页两次取样的层节点身份不一致，门禁失败并说明「切镜只该换图，不该让元素重新入场」

#### Scenario: 包里没有页内镜头

- **WHEN** 对一个不含 `shots` 的包跑本门禁
- **THEN** MUST 以退出码 2 结束并说明「没有页内镜头，无从判断切图」
