# 设计：导出接线与逐页动画编辑（M3）

## ADR-21 动画通道的失败止于「降级」，不进入 `classifyEncodeError`

**决策**：`renderMP4` 里动画通道的调用被包在一个独立的 `tryAnimation` 里，它只返回
`(segments, degraded, err)` 三态：

| 返回值 | 含义 | 后续 |
|---|---|---|
| `segments` 非空、`err == nil` | 正常 | 走拼接 |
| `segments` 为空、`err != nil` | 服务不可达 / 全片失败 | 记录降级，**继续走静态路径** |
| `segments` 部分、`degraded` 非空 | 个别页失败 | 拼接时该页换静态段，成片标注页码 |

**理由**：`classifyEncodeError` 的语义是「静态编码失败，用户该重试或该报错」。动画是增强层，
把它的错误塞进同一个分类器，等于让「渲染服务抖一下」变成「导出失败」——正是 §8.8 明令禁止的。

**代价**：降级是静默的，用户可能不知道自己拿到的是静态版。所以必须有一条可观测的出口：
`animation_degrade_total{stage}`（§11.3）+ 成品行上的 `degraded` 标记，前端据此提示。

## ADR-22 拼接优先 `-c:v copy`，失败才整片重编码

**决策**：分为三条路径，按代价从低到高：

1. **无字幕**：`-f concat -safe 0 -i list.txt -c:v copy`。不重编码，5 分钟片秒级完成。
2. **有字幕**：无法 copy（`-vf` 与 copy 互斥）→ 解码后 `-vf ass=...` 重编码全片。
3. **copy 失败**（分段参数不一致、时间基不连续）：回退到路径 2 的重编码，并记录原因。

**为什么能 copy**：分段由同一后端、同一 `renderProfile`（分辨率 / fps / 编码参数）产出；
单页降级段也由**同一套编码预设**生成（libx264 / yuv420p / 同 fps / 同尺寸），而不是随便找个
ffmpeg 默认参数转一张图——否则 copy 会在某个分段上静默产出坏片。

**输入选择**：`-map 0:v:0` 只取视频流。分段来自渲染服务时无音轨；降级段由 `Encode` 生成，
带一条 `anullsrc` 静音轨——不显式 `-map` 会把这条静音轨也拼进去，最后整片「有声音但全是静音」。

**已知边界**：concat demuxer 不校验每段时长是否等于计划时长。若某段偏短/偏长，成片会整体漂移，
且 ffprobe 的总时长仍可能落在容差内。因此拼接前逐段 ffprobe，累计偏差超 100ms 即把**该页**
改为静态段（静态段时长由我们控制，能精确补齐）。

## ADR-23 单页降级的替换单元是「静态段」，不是「跳过该页」

**决策**：单页失败时，用该页的静态图编码成一段与动画段同参数的 mp4（时长 = 该页计划时长），
替换该段后继续拼接。

**理由**：跳过该页会让成片比时间轴短，音频与字幕整体前移——用户拿到的是「音画不同步」，
比多一张静态图糟得多。替换则保持时间轴逐页对齐这一不变量。

**代价**：该页没有任何动画（用户能看到「这页突然不劲了」），所以必须能告知是哪一页。

## 拼装顺序

```
spec ─compile→ IR ─submit→ renderer ─segment_NNN.mp4→ ┬─ 逐段 ffprobe + 偏差校验
                                                      ├─ 失败页 → 静态段替换
                                                      └─ concat → 混音 → 烧字幕 → 产物
```

## 开关与零副作用

| 开关 | 作用域 | 默认 | 关闭时的行为 |
|---|---|---|---|
| `animation.enabled` | 租户 | false | 导出界面不出现动画选项；`renderMP4` 走原路径 |

**零副作用的定义**：开关关闭时，`ExportSnapshot` 的序列化结果必须与今天逐字节一致
（否则 snapshotHash 变、历史产物全部 miss、幂等键失效）。动画相关字段只能是
`omitempty` 且默认零值——这是本变更最容易踩的隐形回归，需要一条快照哈希的回归用例。

## 风险

| 风险 | 缓解 |
|---|---|
| 分段与静态段参数不一致 → copy 出坏片 | 降级段复用同一编码预设；copy 失败自动重编码 |
| 渲染服务版本漂移 | 调用前 `/healthz` 比对 `schemaVersion`，不符则不调用（§11.5） |
| 动画通道拖长导出时长 | 单页 60s 超时 + 全片上限；超时即降级，不重试到底 |
| 开关关闭仍有行为差异 | snapshotHash 快照用例（见上） |
| 逐页编辑器改动破坏讲稿编辑 | 复用 `scriptState` 的草案/冲突模式，不新建状态机 |
